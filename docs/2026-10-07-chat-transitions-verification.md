# 聊天切换优化验证记录

客户端日期：2026-10-07。分支 `codex/sillytavern-chat-transitions`，基线 `b14fefec7a7b50cdcbf22b987c797ef3960a7fa9`。生产仍是 `/srv/sillytavern` 的 1.18.0、Node 20.20.2；截至只读复核，原白名单源码指纹和进程 PID 未变。本次没有部署、重启、合并或推送。

## 完成的改动

最近角色聊天原来先打开角色默认聊天，再打开点击的历史文件。本次通过 `selectCharacterById` 的可选 `chatFile` 直接进入目标文件，普通调用保留原有 void 返回和菜单行为。保存、生成、角色有效性守卫保留，欢迎页只在成功后保存角色选择，连续重复点击受限。

独立审查发现并修复了双重清空覆盖默认提示词缓存、失败后的默认重试误判，以及旧准备操作清空同角色新聊天三个问题。元数据引用、角色与文件名共同限制准备和持久化，失败恢复正常首页。默认提示词缓存用真实 clearChat/save/loadItemizedPrompts 源码和浏览器 IndexedDB 验证。

`/recent` 的摘要缓存保留原输出、排序、置顶、数量和群聊标记。新鲜 BigInt stat 验证 dev/ino/size/mtimeNs/ctimeNs，读取前后版本一致才缓存。并发读取合并，旧任务不能覆盖新任务；克隆隔离调用者。默认 256 条、8 MiB 估算总容量、512 KiB 单条、256 合并记录、60 秒绝对 TTL。容量为估算值，过期清理发生在访问时；大结果完整返回、不截断、不缓存。搜索、普通读取和写入接口未改。

## 浏览器与后端结果

以下为本机人工场景三次样本中位数。Chrome 154，1440×1000，40 ms 模拟网络延迟，无 GPU headless。统计从原生点击到目标消息、CHAT_CHANGED、CHARACTER_EDITED 完成并经过两帧。默认文件约 7.5 MB，最近入口和退出菜单使用原生处理器；旧前端与候选共用独立实验后端。

独立实验版小文件进入中位数 0.565 秒。每个最终场景保存三次完整样本；六个基本场景共 36 次进出操作，追加大文件场景 12 次。390×844、CPU 降速 4 倍的模拟功能契约通过，但数值波动大，候选退出也有更慢的结果；不作为移动端速度验收。

表格插件会写入 `chat_metadata` 和最后消息的 `hash_sheets`。各条件顺序执行且没有重置这些扩展状态，绝对时延属于探索性本机场景数据。主要可独立确认的收益是一次目标读取、减少默认渲染/事件，以及下面的真实文件读取次数。不能声称实际用户、实际手机或生产环境获得相同秒数。

后端独立 HTTP `/recent` 夹具共 11 个文件、43,181,780 字节；六次等价请求：原始读取 66 个流/259,090,680 字节，兼容缓存版读取 11 个流/43,181,780 字节，后五次均不打开 JSONL 流。暖请求中位数 39.44→6.76 ms，首次仍需读文件。追加一条消息后，只重读这一份，601 条计数和另外十份响应均正确。记录在 `recent-*-final.log` 及 `recent-benchmark/*/results.json`。
