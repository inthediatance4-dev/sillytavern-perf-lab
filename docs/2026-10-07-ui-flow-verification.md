# SillyTavern 夜航主题与交互改进验证

日期：2026-10-07。分支 `codex/sillytavern-ui-flow`，worktree `.worktrees/ui-flow`，父版本 `567300a837f7cef8eb4aa1c5e09d36a8a6901c7c`。本轮没有连接、修改或重启生产服务，没有部署、合并或推送；现有数据没有导入实验版。

## 改进内容

新增可通过原生主题选择器应用的 **After Hours（夜航）**，使用墨蓝、暖铜和乳白，调整聊天、引用/代码、输入区、设置及工具栏。主题由默认内容安装机制分发，以同源 CSS 导入，不修改默认 settings 或已有用户的主题选择，不引入外部字体、图片或依赖。关闭模糊、文字发光；保留消息操作和删除选择的红色语义，支持减少动画。桌面固定几何只覆盖普通模式。

媒体滚动改为单一可取消的批次。上翻阅读时不因迟到媒体跳回底部；重复调用、加载/失败、截止和清空聊天时释放组件自身的监听器。保留原滚动接口、自动滚动偏好、聊天保存格式和生成流程。

浏览器验收发现取消消息编辑后，旧自动补全继续响应窗口大小改变，对已移除的 textarea 调用观察器或读取空布局层。追加有界生命周期修复：释放自身窗口 resize/keyup 监听、观察器、测量克隆和悬浮层；阻止排队回调及旧异步结果恢复失效界面。连接中的定位、解析和选择逻辑保持，构造后挂载及重新挂载仍可用。观察器只监视输入框祖先的直接 childList，不扫描全局 subtree。

## 实际浏览器

内置浏览器运行组件缺少服务文件，改用 Chrome 154 的全新 Playwright 上下文；不读取用户浏览器资料，浏览器外部请求全部阻断。只使用人工角色「夜航助手 · 人工演示」及 180 条明确标注的合成消息，没有请求真实生成模型。

实际旧 `script.js` 的延迟图片场景中，25 次重复调用留下 50 个监听；用户已经上翻 1,200 px，图片就绪仍被拉回底部，监听不释放。本轮同一场景为 2 个监听，完成后为 0，阅读位置和 1,200 px 距离不变；留在底部的场景仍留在底部。

主题通过原生选择器应用、保存、切回 Dark Lite、恢复及新上下文重开。1440×1000、390×844、360×740、768×1024、844×390、390×440 六组实际布局检查通过，多行中文/英文输入保持完整，主体/输入/工具栏在视口内，无页面横向溢出；聊天背景 backdrop-filter 为 none。首版 360 px 工具栏曾超出 17 px，已用等宽点击区域和自适应图标修复，保留全部十个控件，没有裁切隐藏。系统减少动画下相关过渡为 0 s。

最终交互记录 `browser/interactions-61564a4ddc/results.json` 验证：连续三次编辑、取消和 resize 后窗口监听总数 45→45；原消息保持；代码复制内容正确且只写临时捕获器；草稿跨 viewport 与左右侧栏保持；删除选择显示红色后取消，没有删除消息；键盘焦点可见；原生 `/hel` 补全和 Escape 正常。保存接口必须读回 181 行（1 行元数据+180 条消息），验收前后完整 JSON 相同。

一次早期完整性检查用系统编码读取 UTF-8 中文聊天文件名，结果误读为空数组。该记录 `interactions-eff1d8827a` 的存储比较被明确排除，修正编码并增加 181 行及人工元数据断言后重新验收；失败/被替代记录保留，没有清除。初次布局失败和原版自动补全错误也保留。

`acceptance-verification.json` 关联六组有效浏览器记录、测试结果及被排除证据。`final-http-source-check.json` 校验本地服务实际返回的主脚本、媒体模块、自动补全模块和主题 CSS 与最终 worktree 字节一致。

## 保护与交付

实验启动器固定为 `127.0.0.1:8774`，只用当前 worktree 的实验配置和数据，禁止外部/链接数据路径及继承环境覆盖，关闭扩展自动更新、服务器插件与自动开浏览器。只读复用旧 node_modules junction，未安装/升级依赖。端口占用报错，不停止其他程序。

五个旧工作区（主仓库、performance、lifecycle、startup、frontend-startup）的 HEAD、Git 状态和 5,785 份源码 SHA-256 保持；最初六份 `.bak` 及追加的 AutoComplete 原始备份共七份，均核对原始 MD5、SHA-256 与父版本字节。额外实验配置修改前也单独保留副本。本轮没有删除任何文件，失败夹具和原始记录仍在 F 盘或各实验目录。

源代码按十五份白名单交付，不暂存实验配置、用户数据、模型、node_modules、浏览器缓存和结果。源码提交冻结后生成增量 ZIP、完整差异与自包含 Git bundle，再实际恢复 checkout 比较改动字节；最终提交、产物路径和 SHA-256 以 F 盘 `source-manifest.json`、`delivery-verification.json`、`final-verification.json` 为准。该记录在冻结提交后产生，避免将产物自身指纹写回源码造成循环。实验自己的进程在交付前通过带身份校验的控制文件关闭，并确认 8774 释放。

## 未验证及剩余问题

1. 未部署、未做 Linux 生产、真实账号、真实聊天规模、全部插件组合或真实模型生成验收。本轮没有量化 FPS、GPU 帧耗时或线上速度提升比例。
2. 离线浏览器仍有原第三方 st-memory-enhancement 更新检查的 Failed to fetch；相关原始栈和外部阻断保留，不算新核心错误。
3. 快照 `/sounds/message.mp3` 404 和 node_modules junction 引发的默认头像缩略图 WASM 路径限制仍存在，未擅自改第三方依赖。
4. 实验快照缺少完整 ESLint 配置，针对改动文件的命令不能启动；没有声称全仓库 lint 通过。语法、现有 CSS 解析器、接口/生命周期测试和实际浏览器已验证。
5. 原有跨进程聊天事务、活跃 pipeline 释放/切换、向量并发与缓存容量等独立问题没有在本轮解决。主题对 movingUI/waifuMode 的几何排除经源码审查，完整交互组合未做浏览器验收。
