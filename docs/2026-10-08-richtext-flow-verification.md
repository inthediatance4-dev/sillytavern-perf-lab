# 酒馆重富文本聊天加载：隔离验证

日期：2026-10-08。分支：codex/sillytavern-richtext-flow；基线：d7b3de40abbe583620aab9b9b1247e04747dfeee；实现提交：75b17f6。生产服务器未访问、未部署、未重启。本地实验服务127.0.0.1:8777已通过自身控制文件正常退出，PID1856与监听端口已确认不存在。交付包的最终提交与字节校验以外部source-manifest.json和delivery-verification.json为准。

## 实际改动

保留完整、同步的消息构建和DOM提交。角色聊天加载显示的正文达到250000字符时，在printMessages完成后、右侧菜单和CHAT_CHANGED插件收尾前，通过delay(0)让出一次主线程。计数只遍历当前显示的后缀并提前终止；普通小正文、群聊和通用redisplayChat不增加这个边界。

getChat为每次加载建立序号及角色/头像/群组/文件/元数据身份。clearChat进入即使旧序号失效。响应应用、渲染后的继续执行、菜单选择、终结事件和延迟聚焦均检查当前所有权；取消返回false，八处getChat调用继续传播，避免旧加载在关闭/重载后继续保存角色。成功调用保留原来的void返回。插件事件内合法替换元数据后，只在序号与选择仍一致时刷新身份引用。

没有更改消息格式化、净化、宏、消息深度、提示词构造、编辑/滑动/插入的同步渲染。没有引入消息虚拟化、格式化缓存、视口外尺寸估计或新的样式。

## 浏览器结果

同一最终后端，旧脚本使用原文件备份覆盖，新脚本使用候选源码。每种数据各3组旧/新对照，交替执行顺序，每次全新Chrome上下文；桌面1440×1000、headless、disable-gpu、CPU1、模拟网络延迟40ms。所有消息由本次实验生成；未读取真实聊天、未发送生成请求。正式测速不启用CPU采样或Tracing。

| 数据与指标 | 原版中位数 | 候选中位数 |
| --- | ---: | ---: |
| 180条大正文，显示100条：打开 | 3368.7ms | 3647.3ms |
| 同上：最长主线程任务 | 2307ms | 1237ms |
| 同上：关闭 | 440.8ms | 414.6ms |
| 3000条历史，显示100条较短正文：打开 | 1495.5ms | 1449.7ms |
| 同上：最长主线程任务 | 552ms | 554ms |
| 同上：关闭 | 316.4ms | 330.6ms |

大正文最长阻塞缩短46.4%，总打开耗时增加8.3%（约279ms）。这改善长时间单次阻塞，但不代表加载计算量减少。仍有约1.24秒的单次阻塞，不能称为完全流畅。短正文差异不归因为该调度改动。每种数据各6次实际完整mes_text HTML和消息ID相同，底部距离全部为0，目标聊天读取均为单次。小样本和本地无GPU环境不代表用户服务器、真实手机或所有主题/扩展。

验收门在大正文对照结果之前声明：最长任务中位数至少改善25%，总打开耗时最多增加20%，且功能不回归；候选满足该门。详细原始记录见matched-browser-verification.json和performance-acceptance.json。

## 排查记录与剩余问题

CPU/Tracing发现富文本构建后紧接同步布局/样式与插件可见性读取；采样带有额外开销，不能将嵌套事件时间相加当作正常打开耗时。单加layout/style containment无收益。content-visibility实验破坏滚动，底部差达10135px，已否决；相关机制与尺寸限制可参阅[浏览器官方说明](https://web.dev/articles/content-visibility)。逐条构建让出主线程的实验存在全局消息、推理、滑动与宏副作用，未采纳。

边界验收脚本的四次失败保留：前三次错误假设首页应无消息或消息全为系统消息，实际首页包含助手问候和欢迎提示；第四次错误要求同文件重试必须发生角色编辑事件，实际直接加载已有文件无需编辑。修正验收脚本后，以实际首页基线及CHAT_CHANGED判定；没有因此修改应用源码。最终完整边界检查通过，原因与日志见browser-harness-corrections.json。

既有loadItemizedPrompts仍可能在内部存储等待之后写入全局提示词并发出内部事件，调用者只能在它返回后判断是否过期。本轮新增边界位于它完成之后，不声称解决这个旧竞态，也不能中断已执行中的第三方插件监听器。后续优先处理该提示词内部所有权，并进一步缩短剩余同步富文本和布局开销。

实验环境已有的st-memory外部更新请求被阻断、message.mp3缺失、依赖junction导致WASM缩略图权限错误均保留记录；没有放宽路径保护，也没有将这些问题判断为线上故障。本轮没有真实模型API、真实设备或生产UI验收。
