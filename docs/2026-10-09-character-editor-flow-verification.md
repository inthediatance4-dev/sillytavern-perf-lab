本轮在 `codex/sillytavern-character-editor-flow` 隔离分支完成，基线 `cfeca4bf431403a5e0204a8e2f8150ac8dc83759`；证据在 `F:/SillyTavern-Research/2026-10-09-character-editor-flow`。未访问生产、未部署或重启线上服务、未安装依赖、未执行删除清理。候选仍沿用既有实验源码，不是官方新版整包，增量 ZIP 不能直接覆盖生产。

## 修改

打开角色编辑器时，旧流程先填入整份新建草稿、切换按钮、格式化草稿创作者备注、刷新世界书/收藏状态，再立即用当前角色重新做一遍。给私有准备函数增加默认开启的 resetForm 选项；选中角色时关闭草稿重置，只保留菜单与三个此前继承的控件复位，再一次填入当前角色。同时去除角色版本字段的重复写入。

新建角色仍按默认完整恢复草稿。角色字段、深度默认值、世界书、收藏、媒体许可、来源按钮、群聊成员查看、switchMenu:false、编辑器事件与设置保存顺序、void返回保持兼容。create_save、角色数据和 FileList 没有因为这项优化而被修改；原有 read_avatar_load 异步草稿头像/裁剪/保存路径保留，这项优化没有修复其已有异步副作用。消息格式化、渲染、提示词所有权、聊天调度和 API 均未改。

## 浏览器测量

同一候选后端、同一静态资源，只对照基线 cfeca4bf 主脚本和当前主脚本。普通与重型人工历史各三对，交替旧/新顺序，每次新 Chrome 临时上下文。headless disableGPU、CPU1、模拟40ms延迟；未使用个人浏览器资料，外部请求阻断，模型生成请求为零。两个版本都只加相同的两次 performance.now 和一条仅在测量期间记录的编辑器耗时；没有改变 DOM、格式化或任务边界。样本小，不能外推到生产或真实手机。

12个测量结果均验证源脚本指纹、目标只读一次、180条模型及编号80–179的100条DOM。每类数据全部6次的实际 mes_text HTML字节一致，底部距离均为0。原始 JSON、HTML、日志与 source overlay 信息保留，见 matched-browser-verification.json 和 performance-acceptance.json。
