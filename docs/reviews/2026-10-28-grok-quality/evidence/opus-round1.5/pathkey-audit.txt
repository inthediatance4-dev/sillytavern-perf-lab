Path-key audit — round 1.5 follow-up / round 2

Scope: src/ locks, retirement markers, reuse authorization, import epochs,
backup pendingPaths and pendingChatIOPaths. No windowsPathKey realpath cache.

Findings:
- normalizeLockRequests calls pathKey for every gate/held-mode key.
- markerPath hashes path.relative(pathKey(root), pathKey(file)); its filename
  contains no absolute-root spelling. The marker lives at root/.chat-lifecycle/.
- relative_path records the path relative to the supplied lifecycle root, not
  the root itself. assertChatWritable checks file and (when below root) parent
  candidates using markerPath. Both short/long root directions are tested.
- Reuse authorization binds canonical marker keys with pathKey, checks validity,
  and requires a canonical exclusive held key.
- Import epochs use pathLockKey for both creation/check and invalidation.
- pendingChatIOPaths flattens already-normalized reservation request keys.
- Backup pendingPaths returns scheduler state.key, passed in by backupIdentity.
  Fixed backupIdentity's raw resolve/toLowerCase to call pathLockKey.
- windowsPathKey resolves the longest existing prefix on every call, with a
  call-local missing-suffix array. No realpath result cache exists.
- Remaining toLowerCase calls concern text, flags, extensions, asset names,
  usernames, MIME types or the single windowsPathKey normalization entry point;
  none construct lifecycle/lock/backup path identities.

import path from 'node:path';
import fs from 'node:fs';

/** Expand DOS short names in the existing prefix, including for unpublished files. */
export function windowsPathKey(filePath, realpath = fs.realpathSync.native) {
    let current = path.win32.resolve(filePath);
    const missing = [];
    while (true) {
        try {
            return path.win32.join(realpath(current), ...missing).toLowerCase();
        } catch (error) {
            if (error.code !== 'ENOENT') throw error;
            const parent = path.win32.dirname(current);
            if (parent === current) throw error;
            missing.unshift(path.win32.basename(current));
            current = parent;
        }
    }
}
