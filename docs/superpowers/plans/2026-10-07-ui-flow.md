# SillyTavern UI Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可切换的 After Hours 主题，修复迟到媒体抢滚动和残留监听，并完成隔离验收。

**Architecture:** 主题沿用 default/content 的现有分发及 custom_css 接口。媒体滚动使用一个独立的有期限、可取消的批次管理器，主脚本仅提供当前用户意图和原滚动接口。

**Tech Stack:** 原版原生 JavaScript、jQuery、CSS、主题 JSON、node:test、Chrome 本地人工场景；不安装或更新依赖。

文件：新建 `public/scripts/media-load-scroll.js`、`tests/media-load-scroll.test.mjs`，修改 `public/script.js`。原脚本已备份，MD5 `304e6ef604e3baa542f10ee71604401d`。

- [ ] 编写实际旧代码的反例，使用原生 EventTarget 和 getEventListeners 检查用户上翻、重复订阅、取消/截止释放以及 load/error 双事件。
- [ ] 运行 `node --test tests/media-load-scroll.test.mjs`，保留失败日志到 F 盘 `media-scroll-red.log`，确认失败是预期行为。
